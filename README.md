# trpgC — マギカロギア プロトタイプ

このリポジトリにはマギカロギア用のキャラクターシートプロトタイプが含まれます。

主な機能
- 立ち絵アップロード → トリミング（正方形） → 512×512 PNG 出力
- マギカロギアの蔵書（grimoires）を編集し、ココフォリア用 JSON を生成
- chatPalette の自動生成
- PWA（manifest + service worker）対応、noindex を埋め込み

使い方
1. GitHub Pages を有効化してください（Settings → Pages）。
2. 公開されたページで立ち絵をアップして調整、"512×512 PNG を生成" をクリックしてダウンロードしてください。
3. "ココフォリア用JSON生成" をクリックするとクリップボードへコピーされ、JSONファイルもダウンロードされます。

注意
- 公開リポジトリのため、noindex を入れていますが完全な非公開化は保証できません。
- 画像は大きいとメモリを消費します。iPhone Safari などでは自動的に縮小されますが大量の大サイズ画像は避けてください。
